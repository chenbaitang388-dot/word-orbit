# Word Orbit · 单词探索站

面向小学生和家教课后练习的独立网站。与作者个人使用的 word-memo 分开维护，使用独立存储键和离线缓存。

## 功能

- 首次访问选择「宇宙探索 / 可爱小岛」，之后记住选择，随时切换。
- 七册人教 PEP 新版教材词库，共 876 个教材词条（含四下数词补充）；另有六个趣味主题词库，共 72 个词条；用户自己的词库只在本机处理和保存。
- 上传 Excel（第一张工作表）、CSV、TSV、TXT、JSON；也能粘贴单词。先检查、去重、预览，再确认导入。文件上限 5 MB。
- 闪卡自评、四选一、中文回想拼写；到期词优先、每日新词限额、每轮最多 10 个初始词，答错在本轮末尾再练一次。
- 拼写题内置 QWERTY 字母键盘，避免系统输入法自动提示，支持电脑实体键盘与空格、连字符、撇号、退格。
- 两套主题音色，点击、翻卡、输入、正确、错误、完成练习采用不同反馈；设置中可静音、调节音量，音效本地合成并支持离线。
- 两套世界各有一首背景音乐，循环轻声播放；首次点击后开启，可独立开关及调音量，偏好保存在本机。切后台暂停、单词发音时自动压低背景音乐；完整缓存后可离线播放。音乐来源与 CC BY 4.0 授权见 `dist/MUSIC_CREDITS.txt`。
- 星能/星星、等级、徽章、学习足迹。每词每日首次作答奖励 2 分，认识或答对共奖励 5 分，重复刷题不重复加分。
- 本机自动保存；完整 JSON 备份导出、合并、覆盖恢复，支持手动迁移设备。没有账号，也没有自动跨设备同步。
- 响应式电脑、手机和平板布局；首次联网完整缓存后可离线使用。发音使用系统 speechSynthesis，语音和离线支持因设备而异。

## 本地运行

需要 Node.js，应用本身无构建步骤。

```sh
node serve.mjs
```

打开 http://127.0.0.1:8137 。静态发布目录为 `dist/`。

## 作者更新预置词库

编辑 `dist/src/presets.js` 中的 `PRESETS`。按册教材词库在 `dist/src/textbooks.js`；五年级上册沿用 `dist/src/grade5.js`，保留原词库 ID。教材词条保留原顺序、单元及页码，四下数词表标为独立补充；同拼写不同释义在练习池中合并展示，避免丢掉后出现的词义。六年级下册尚无可核验原页，未用旧版补入。每个词库包含固定 id、名称、说明和 `words: [[英文, 中文], ...]`。新增词库后重新发布即可；现有学生导入的私人词库不会上传到服务器。

当前预置词库是复制到学生本机使用，作者修改预置内容不会覆盖学生已保存副本。第一版没有作者在线后台。

## 扩展个性化风格

在 `dist/src/themes.js` 的 `THEMES` 增加 id 和描述、颜色、称号、标题等；在 `dist/styles.css` 添加 `:root[data-theme=新id]` 变量；在 `starsArt` 插画入口扩展视觉。选择页和切换器会自动读取主题列表。主题与学习记录独立，禁止把学习进度放进主题对象。

`dist/src/access.js` 预留未来服务端授权适配接口；目前不会验证授权、收款或限制使用。后续收费服务应在服务端验证订单和资格。

## 部署

部署任意支持静态文件的商业可用托管服务，发布目录 `dist/`。本项目附 GitHub Actions 的 Pages 发布配置供免费演示使用，需在仓库设置中启用 Pages 的 GitHub Actions 来源。

将来若改为商业 SaaS 或主要用于促成商业交易，不应把 GitHub Pages 作为免费商业托管；保留 GitHub 管理源码，另选适用的正式托管。

新版本修改 `dist/sw.js` 的 CACHE 版本号，离线客户端下次联网打开时更新。站点地址之间不会自动共享本机记录，请使用备份迁移。

## 检查

- `node backup-regression.mjs`：备份深校验、积分合并、多标签页冲突回归。
- `node textbooks.test.mjs`：七册教材词库数量、原有词库兼容、同词多义、手机排版和离线缓存。
- `node sound-keyboard.test.mjs`：差异化音效、静音、音量及站内拼写键盘。
- `node music.test.mjs`：背景音乐开关、主题曲、音量、发音压低、后台暂停、自动播放限制和离线缓存。
- `node core.test.mjs`：复习调度、选择题、解析等继承逻辑检查。
- `node qa.mjs`：本机完整浏览器流程，需要按本机路径调整 Playwright 和 Chrome；测试脚本不属于网站运行依赖。
